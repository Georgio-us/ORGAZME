# ORGAZME

Personal Business Operating System: мобильная рабочая среда для управления
клиентским контекстом, событиями, задачами и AI-предложениями.

## Текущий срез

- главный экран с направлениями «Клиенты», «Финансы» и «Направления»;
- клиентский dashboard и компактный список;
- карточка клиента с dashboard и лентой событий;
- контекстная action-кнопка:
  - короткое нажатие открывает выбор типа действия;
  - удержание запускает голосовую запись;
- экран проверки AI-предложений до их применения;
- PostgreSQL-схема для пользователей, клиентов, событий и AI-предложений.

Клиенты, события и подтверждённые AI-изменения сохраняются в PostgreSQL.
При первом запуске база получает демонстрационный набор клиентов, после чего
любые изменения выполняются уже над постоянными данными.

## Стек

- Next.js 16, React 19, TypeScript;
- Tailwind CSS 4 и собственный mobile-first UI;
- PostgreSQL, Drizzle ORM;
- Railway.

## Локальный запуск

Требуется Node.js `>=22.13.0`.

```bash
cp .env.example .env.local
npm install
npm run dev
```

Открыть `http://localhost:3000`.

## Проверки

```bash
npm run lint
npm run build
```

## База данных

Railway автоматически предоставляет `DATABASE_URL` после подключения
PostgreSQL-сервиса. Перед каждым Railway-деплоем выполняется `db:migrate`.
Для локальной генерации и применения миграций:

```bash
npm run db:generate
npm run db:migrate
```

## AI и голос

Серверная переменная `OPENAI_API_KEY` включает живую обработку записи:

1. `gpt-4o-transcribe` преобразует голос в текст;
2. `gpt-5.6-terra` формирует структурированные предложения;
3. пользователь принимает или отклоняет каждое предложение;
4. принятые изменения транзакционно сохраняются в PostgreSQL.

Ключ используется только на сервере и не должен иметь префикс `NEXT_PUBLIC_`.
